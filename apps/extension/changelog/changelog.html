Extension versions

0.3.0

  • Emails are now actually collected. Until now the Email column was always empty: Google Maps never returns an email and nothing else looked for one. The extension now opens each business's own website (home, then contact / about / imprint pages) and saves the address it finds, with the page it came from.
  • Find emails while scraping (popup switch, on by default) — runs in the background next to the scrape; in “Stream to DB” mode a finished search waits for its lookups before it is uploaded.
  • Email audit page — per project: what is missing, how much and where; pick the project to start from; works on the database or on this browser's projects.
  • Changelog page (this one).
  • Fixed: re-scraping or re-syncing a project blanked an email that had already been found.

0.2.0

  • Reads Google Maps' search responses instead of the page (reliable website / phone), multi-window batch engine, stream-to-database mode.
